# Mixue Database Development Project

## Project Overview
This project focuses on designing and developing a relational database system for Mixue, a beverage and dessert franchise.

## Technologies Used
- Oracle SQL
- SQL Developer / SQL*Plus

## Project Features
- Database design and ERD
- Business rules development
- Database table creation
- Primary Key and Foreign Key implementation
- Sample data insertion
- SQL queries and reports
- Query testing and results
